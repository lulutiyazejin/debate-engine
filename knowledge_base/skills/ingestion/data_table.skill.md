# SKILL: 数据表格入库分析

## 适用文档特征
- Excel / CSV 等结构化行列数据
- 统计年鉴、调查数据、财务报表、指标对比表

## 摘要生成规则
1. 先说明表格主题与统计口径（时间范围、单位、来源）
2. 转述为自然语言段落，不逐行罗列数字
3. 点出最大值/最小值/趋势拐点等关键信息
4. 200 字以内

## 论证单元识别规则
- 一组能支撑某个结论的数据（如"近十年基尼系数上升"）成一个单元
- claim 写数据支持的结论，evidence 写具体数字与出处行列
- 纯数据无结论时不强行造论点

## 坐标提取注意
- 数据本身通常中性，各轴倾向依编制方叙事框架判断
- 无明显立场倾向填 0

## 质量检查
- 摘要必须包含至少一个具体数字
- 不得虚构表中不存在的数据
