# Debate Engine 0.1.1 · Windows 安装包

带立场的本地 RAG 反驳引擎——桌面版（窗口界面，全程无命令行窗口）。

## 安装

双击 `DebateEngine-0.1.1-Setup.exe`，程序将安装到
`%LOCALAPPDATA%\Programs\DebateEngine`（可改），并在桌面与开始菜单创建
「Debate Engine」快捷方式。

## 快速开始

双击「Debate Engine」即打开窗口程序，八个功能页：

1. **反驳**：输入对方论点 → 选立场/格式/风格 → 流式生成带引用的反驳
2. **搜索**：全库/立场内检索，关键词高亮，一键作为反驳素材
3. **导入**：拖拽或选择 PDF/Word/Excel/TXT/MD/文件夹/URL，实时进度
4. **对比**：库内两文档、粘贴文本对比，或同立场内部分歧地图
5. **图谱**：论证单元关系图（支持/攻击/细化），节点右键可纠错
6. **报告**：跨立场综合报告（先预估 token 再生成，可导出 Markdown）
7. **溯源**：论点思想史溯源（库内证据按年代排序，模型推测异色标注）
8. **设置**：AI 服务商 Key 管理、知识库导出/导入分享包（.debkb）

命令行用法保留：安装目录 `engine\` 已加入用户 PATH，新开终端可用
`DebateEngine health / import / rebut / search / serve`。

## 配置 AI 服务商（可选但推荐）

不配置任何 Key 时软件以离线模式运行（仅检索+模板输出）。
在「设置」页直接填 Key，或在安装目录创建 `.env` 文件：

```env
GROQ_API_KEY=gsk_...
GEMINI_API_KEY=...
CEREBRAS_API_KEY=...
# 本地 Ollama 无需 Key，运行 ollama serve 即自动检测
```

## 预置立场（knowledge_base/skills/stances/）

liberal（古典自由主义）/ marxist（马列毛主义）/ conservative（保守主义）
/ social_democracy（社会民主主义）/ empirical（经验主义数据派）

Skill 文件为 Markdown 格式，可自行编辑或新增。

## 数据位置

- 知识库（SQLite + 向量库 + 归档原文）：安装目录 `knowledge_base\`
- 日志（JSONL，隐私分级）：`knowledge_base\logs\`

## 卸载

「设置 → 应用 → Debate Engine → 卸载」，或运行安装目录的 `Uninstall.exe`。
卸载时可选择保留知识库数据。
