# Debate Engine 0.1.0 · Windows 安装包

带立场的本地 RAG 反驳引擎（核心引擎 CLI 验证版，无桌面 UI）。

## 安装

双击 `install.bat`，程序将安装到 `%LOCALAPPDATA%\Programs\DebateEngine`
并自动加入用户 PATH（新开终端生效）。

也可免安装直接运行 `DebateEngine\DebateEngine.exe`。

## 快速开始

```bat
:: 1. 健康检查（查看依赖与服务商状态）
DebateEngine health

:: 2. 导入一篇文档（PDF/Word/Excel/TXT/MD/URL）
DebateEngine import 通往奴役之路.pdf --stance liberal

:: 3. 生成反驳（3 种格式 × 8 种风格）
DebateEngine rebut "计划经济优于市场经济" --stance liberal --format quick

:: 4. 搜索知识库（立场隔离）
DebateEngine search "市场失灵" --stance liberal

:: 5. 启动 HTTP API（http://127.0.0.1:7700/docs）
DebateEngine serve
```

## 配置 AI 服务商（可选但推荐）

不配置任何 Key 时软件以离线模式运行（仅检索+模板输出）。
在安装目录创建 `.env` 文件，填入任一免费服务商 Key 即自动启用：

```env
GROQ_API_KEY=gsk_...
GEMINI_API_KEY=...
CEREBRAS_API_KEY=...
# 本地 Ollama 无需 Key，运行 ollama serve 即自动检测
```

## 预置立场（knowledge_base/skills/stances/）

liberal（古典自由主义）/ marxist（马列毛主义）/ conservative（保守主义）
/ social_democracy（社会民主主义）/ empirical（经验主义数据派）

Skill 文件为 Markdown 格式，可自行编辑或新增。

## 数据位置

- 知识库（SQLite + LanceDB + 归档原文）：安装目录 `knowledge_base\`
- 日志（JSONL，隐私分级）：`knowledge_base\logs\`

## 卸载

删除 `%LOCALAPPDATA%\Programs\DebateEngine` 目录，并在
「编辑系统环境变量 → 用户 Path」中移除该条目。
